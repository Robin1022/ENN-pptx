# 自适应版式与内容密度

页面布局由内容量、逻辑关系和信息优先级决定。模板提供视觉语言和可复用原型,但不得强制内容沿用原页面的容器大小、栏宽或形状数量。

## 一、布局前的内容盘点

为每个内容组记录：

- 信息任务：背景、问题、洞察、方案、架构、对比、数据或行动。
- 条目数及每条的预计文字量。
- 优先级：核心结论、主证据或辅助说明。
- 视觉类型：文字卡片、图表、架构图、流程、大数字或图片。
- 预计占用高度和宽度。

内容区域占比应参考“条目数 × 平均文字量 × 优先级”,而不是简单平分。信息量差异明显时,不使用等宽、等高的固定容器。

## 二、按数量选择基础网格

| 同类内容数量 | 优先布局 |
|---|---|
| 1 | 通栏重点块、大数字或主视觉 |
| 2 | 左右双栏或上下双卡片 |
| 3 | 三等分卡片；主次不同时用主区+双副区 |
| 4 | 2×2 网格 |
| 5–6 | 2×3 或 3×2 网格 |
| 存在前后关系 | 横向流程、时间线或阶梯 |
| 存在主次关系 | 主内容区+辅助侧栏 |

同一页同时存在“少量背景+多个问题+多个方案”时,优先使用“上方背景摘要+下方问题/方案双栏网格”,不要让少量背景独占一个整高大栏。

## 三、整页低密度判断与补救

不只比较各区域之间是否平衡,还要判断整页总信息量是否足以支撑一张完整幻灯片。出现任一情况时,将该页标记为“低密度页”：

- 全页只有 3 个或更少的内容组,每组只有 4 条或更少的短句,且没有图表、架构图或主视觉。
- 页面主体内容预计只需要可用正文区高度的 40% 或更少。
- 为了填满画布,需要把卡片拉到其实际内容高度的 1.8 倍以上。
- 主要正文被压到 16pt 或更小,但容器仍留有大量空白。

低密度页按以下顺序处理：

1. **先判断是否需要补充有价值的信息**：例如阶段目标、关键任务、交付物、验收门槛、决策点、依赖或风险。用户未提供时,按 `PLANNING.md` 用 `[推理补充]` 或 `[待确认假设]` 标记;需要外部事实时按 `RESEARCH.md` 检索。只补充能改善决策信息的内容,不写套话填空。
2. **如果不应补充,则改用紧凑版式**：使用中等高度卡片、横向时间线、里程碑节点、下方交付物/价值总结带,或将该页与相邻页合并。
3. **使用低密度字号档**：卡片标题 24–28pt,主要正文 18–22pt,阶段/时间标签 16–18pt。不得在大量空白页上继续使用 14–16pt 的小正文。
4. **容器高度随内容收缩**：文字卡片高度不得超过其内容实际需求高度的 1.8 倍;卡片内文字和有意义的视觉元素应占据可用高度的 55%–80%。

三阶段实施路径页的默认紧凑结构是：

```text
页面结论/导语
       ↓
三阶段横向时间线
       ↓
三张中等高度阶段卡（目标+关键任务+交付物）
       ↓
下方里程碑/验收门槛/预期价值总结
```

不使用三个从文字结束一直延伸到页底的空白大框。

## 四、模块改造规则

- 先匹配模块的论证逻辑,再重新计算各区域占比。
- 某区域只有 1–2 条短内容时,不保留整高大容器;改成顶部摘要、横向卡片或窄侧栏。
- 某区域条目多且文字长时,扩大该区域、改为网格或拆分到下一页,不通过缩小字号硬塞。
- 反思模块中“认知/现状”远少于“痛点/方案”时,优先改为顶部现状摘要+下方痛点和方案双栏。
- 架构图的层数、对比维度和流程节点数不同时,必须重新绘制主图,不只替换文字。

## 五、无效留白检测

留白只在用于强调核心结论、分隔逻辑或承载视觉焦点时才是有意留白。出现任一情况时必须重排：

- 主要容器内容占用高度低于容器的 45%,且容器下方连续空白超过 35%。
- 页面存在超过画布 20% 的连续空白区,且该区域没有承担强调或分隔作用。
- 最密集区域与最稀疏区域的内容占用高度比超过 1.6:1。
- 内容只集中在大容器顶部,而相邻区域已经拥挤或出现小字号。
- 卡片被单纯拉高以填补空白,但内容仍集中在顶部。
- 整页主要正文不超过 12 条短句,却使用三个或更多的整高容器。
- 卡片内文字/视觉元素占用高度低于 55%,且留白不承担任何意义。

修复顺序：先调整内容分组 → 改变区域比例 → 更换网格/上下结构 → 必要时拆页。不使用“放大空卡片”或“增加装饰形状”掩盖问题。

## 六、视觉 QA 闭环

1. 渲染每一页成图片。
2. 先检查溢出、重叠和 Logo 冲突,再检查左右/上下视觉重心。
3. 对每页回答：最大的空白区在哪里？它是否有明确作用？最拥挤的区域是哪里？能否把空间从稀疏区转给拥挤区？这页是“应该补充有价值信息”还是“应该收缩容器/合并页面”？
4. 命中无效留白阈值时重排页面,重新渲染修改页,直到阈值不再命中。
