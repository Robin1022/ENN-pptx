| 文件 | 是否入库 | 说明 |
|---|---|---|
| `company-template.pptx` | ❌ 不入库 | 整个 skill 的视觉约束来源。内含真实内部示例文案,被 `.gitignore` 排除,需自行放置 |
| `campus-hire-defence.pptx` | ✅ 已入库 | 校招生转正答辩的场景模板,已清空全部个人信息 |

---

## company-template.pptx —— 需要自行放置

它是 `COMPANY_STYLE.md` 全部数值的来源(画布尺寸、配色、字体、Logo 坐标、9 个可实例化版式,以及 3 个可复用的内容原型页)。

**它没有入库。** 模板文件里带着真实的内部示例文案,不适合放在公开仓库中。把公司模板放到这里并命名为:

```
templates/company-template.pptx
```

没有这个文件时,`SKILL.md` 里所有"从模板实例化"的流程都无法执行。

### 模板需要满足的前提

`COMPANY_STYLE.md` 里的数值是从原始模板实测得出的,换用其他模板时需要同步核对:

- 画布 `12192000 x 6858000` EMU(13.33in x 7.5in,16:9)
- `slideMaster1` 承载 Logo,9 个版式 `slideLayout1.xml` ~ `slideLayout9.xml` 会自动继承
- `slide1.xml` / `slide2.xml` / `slide3.xml` 为三个内容原型页,是 `MODULES.md` 的复制源

模板结构不同时,先运行 `python scripts/thumbnail.py <模板>.pptx template-thumbs` 重新做一次版式盘点,再据此更新 `COMPANY_STYLE.md` 的版式一览表和配色表。

## campus-hire-defence.pptx —— 校招生转正答辩场景模板

14 页,从 HR 的「新进人员任前答辩」表单改造而来,针对**校招生转正**场景调整过措辞与结构。**全部内容为占位提示,不含任何个人信息。**

### 页面结构

| 页 | 内容 | 版面 |
|---|---|---|
| 1 | 封面 | 标题 + 副标题 + 答辩人 / 所在组织 / 答辩时间 |
| 2 | 目录 | `01/02/03` 大编号 + 章节名 + 一行内容提要 |
| 3 | 章节隔页 ① | 大编号 + 章节名 + 右侧出血配图 |
| 4 | 1.1 个人基本信息概述 | 教育背景 2 张卡 + 实习经历 3 张卡,每卡带机构 logo 位 |
| 5 | 1.2 项目与科研经历 | 2×2 项目卡网格 |
| 6 | 章节隔页 ② | 同 ① |
| 7 | 2.1 试用期间的工作总结 | 表格(序号 / 工作要项 / 起止时间 / 团队 / 输出 / 个人贡献) |
| 8 | 2.2 主要发现、问题思考与改进建议 | 发现 / 思考 / 建议 三卡 |
| 9 | 2.3 从校园到职场的转变与自我复盘 | 认知转变 / 方式转变 / 自我复盘 三卡 |
| 10 | 章节隔页 ③ | 同 ① |
| 11 | 3.1 对转正岗位及定位的理解 | 岗位信息 + 三卡 |
| 12 | 3.2 转正后的工作计划 | 工作重点 / 推进方式 / 阶段目标 三卡 |
| 13 | 3.3 能力提升路径 | 首月 / 3 个月 / 6 个月 / 12 个月 时间轴 |
| 14 | 结尾 | 谢谢 |

### 相对 HR 原表单的调整

原表单按社招/晋升设计,以下几处对校招生不成立:

- `1.2 过往业绩亮点、能力专长及**资源情况**`(客户及社会资源)→ `1.2 项目与科研经历`
- `3.1 对**拟任**角色的理解` → `3.1 对**转正岗位**及定位的理解`
- `3.2 工作重点、推进策略、目标**承诺**` → `3.2 转正后的工作计划`(承诺业绩指标是带团队岗位的话术)
- `3.3 **年度**重点工作落实思路`(Q1–Q4)→ `3.3 能力提升路径`(按成长阶段)
- 新增 `2.3 从校园到职场的转变与自我复盘` —— 校招转正答辩的核心考察点,原表单没有

### 使用方式

直接复制一份改文字即可,不需要经过 `company-template.pptx` 的实例化流程:

```bash
cp templates/campus-hire-defence.pptx ~/Desktop/我的转正答辩.pptx
```

第 4 页的 `LOGO` 位是普通形状,插入自己的图片盖上去、或删掉替换。
